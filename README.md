# 🚀 Career-Path-Generator (AI-Powered)

[![MERN Stack](https://img.shields.io/badge/Stack-MERN-blue.svg)](https://mongodb.com)
[![Python FastAPI](https://img.shields.io/badge/AI-FastAPI-green.svg)](https://fastapi.tiangolo.com)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

An intelligent, adaptive career strategist that moves beyond static roadmaps. Using RAG (Retrieval-Augmented Generation) and NLP, it analyzes your current skills, identifies market gaps, and builds a personalized 12-week execution plan.

---

## ✨ Key Features
- **Intelligent Profiling:** Upload your resume (PDF) for automated skill extraction using SpaCy.
- **Dynamic Roadmaps:** 12-week personalized learning paths with curated resources.
- **Skill Gap Radar:** Visualize your current status vs. industry requirements via interactive charts.
- **AI Career Mentor:** RAG-based chatbot to answer career-specific queries using real-time data.
- **Portfolio Snapshot:** Shareable public link for recruiters to see your progress.

---

## 🛠 Tech Stack

### Frontend (The Body)
- **React.js** & **Tailwind CSS** (Glassmorphism UI)
- **Framer Motion** (Smooth Animations)
- **Chart.js** (Data Visualization)

### Backend (The Heart)
- **Node.js** & **Express.js**
- **MongoDB** (Database)
- **JWT** (Secure Authentication)

### AI Service (The Brain)
- **Python FastAPI**
- **LangChain** & **Gemini/OpenAI API** (RAG Engine)
- **ChromaDB/Pinecone** (Vector Database)
